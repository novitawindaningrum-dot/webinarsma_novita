FROM ONE IDEA TO GLOBAL INSPIRATION
Interactive Storytelling Presentation for Novita Windaningrum, S.Pd.
Webinar Direktorat SMA · Sharing Practice · 19 November 2026

CARA PENGGUNAAN UNTUK WEBINAR (ZOOM / GOOGLE MEET)
1. Buka file `index.html` menggunakan peramban modern (Google Chrome atau Microsoft Edge direkomendasikan).
2. Tekan tombol [F11] atau klik tombol "⛶ Layar Penuh" di bilah navigasi bawah untuk tampilan penuh tanpa bilah peramban.
3. Bagikan layar (Share Screen) di Zoom atau Google Meet. Pilih opsi "Share Window" atau "Share Screen" dengan optimasi teks/presentasi.
4. Gunakan tombol panah keyboard (← / →), tombol spasi, atau wireless presenter clicker untuk berpindah slide.

FITUR KHUSUS WEBINAR:
- [Mode Zoom / Fast Slide (Default)]: Transisi cepat (0.25s) yang ringan tanpa lag atau patah-patah di koneksi video konferensi.
- [Mode 3D Flip]: Tekan tombol "T" atau klik tombol "Mode Zoom" di bawah untuk beralih ke animasi buka buku 3D realistis jika presentasi langsung/offline.
- [Daftar Semua Slide (Q&A)]: Tekan tombol "G" atau "O" atau klik "⊞ Slides" untuk membuka kisi 13 slide dan melompat seketika ke slide yang ditanyakan audiens.
- [Mode Layar Bersih (Clean Screen)]: Tekan tombol "H" atau klik "👁 Bersih" untuk menyembunyikan semua menu/tombol agar layar 100% bersih seperti slide PowerPoint.
- [Panduan Tombol Pintas]: Tekan tanda tanya "?" pada keyboard untuk melihat daftar shortcut presenter.
- [Zoom Gambar (Lightbox)]: Klik pada gambar atau sampul buku untuk memperbesar detail dokumentasi.
- [Live Demo PintuARA]: Pada Slide 12 (Live Demonstration), gunakan tombol [Alt + Tab] untuk beralih ke jendela aplikasi PintuARA.
